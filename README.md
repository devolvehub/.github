# .github

Default community health files for every repository in this organisation.

GitHub uses the files in this repository for any `devolvehub` repository that does not carry
its own copy — `CODE_OF_CONDUCT.md`, `CONTRIBUTING.md`, `SECURITY.md`, `SUPPORT.md` and the
issue and pull-request templates under `.github/`. A repository's own file replaces the default
entirely rather than adding to it.

`profile/README.md` is what visitors see on the organisation's Overview tab.

**A licence is never inherited.** GitHub states the reason: the file has to be physically
present in a repository so it travels with a clone, a download or a package. Every repository
here carries its own `LICENSE`.
