# Support

## Where to ask

- **A bug, or something clearly wrong** — open an issue on the repository.
- **A question about using it** — open an issue too, unless the repository has Discussions
  enabled; then ask there.
- **A security problem** — neither. See [SECURITY.md](SECURITY.md).

## What you can expect

Check the repository's README first: it states whether the repository is a **showcase**
(usable, not staffed — issues are read, an answer is not promised) or **maintained** (issues
and pull requests get a first human reply).

This is not a commercial support channel, and there is no service level behind it. Saying that
plainly is more useful than an unanswered question that looked like it would be answered.
