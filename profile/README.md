# devolvehub

Software built for our own work, published because it turned out to be useful beyond it.

Most of what lands here comes from a working day rather than a plan: tooling for Claude Code,
small MCP servers, fast read-only CLIs for analysing code and repositories, and the occasional
thing that grew out of a workshop problem. It is published after it has proven itself in use,
not before.

## What a repository here tells you before you install it

Every repository states its support level in the first section of its README. There are two,
and the difference is a commitment rather than a mood:

**Showcase** — usable, and not staffed. Read it, copy it, fork it. Issues are read; an answer
is not promised. Most repositories here are this, and saying so is more useful than silence
that implies otherwise.

**Maintained** — issues and pull requests get a first human reply. Fewer repositories carry
this label, on purpose: a promise nobody keeps is worse than one nobody made.

Every repository also carries its licence in the repository itself, states how to report a
security problem, and is written in English throughout.

## Contributing

The [contribution guide](https://github.com/devolvehub/.github/blob/main/CONTRIBUTING.md)
applies to every repository here. The short version: check the support level first, open an
issue before a large pull request, and expect a plain answer either way — including "no,
and here is why".
